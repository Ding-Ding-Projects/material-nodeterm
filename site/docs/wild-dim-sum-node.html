Canvas

Wild dim sum node

This page documents an installed-app canvas feature. The documentation site does not run the node or replace the installed app.

Choose from the public catalog

Create the node from the Unified Node Catalog, then choose a random published dish or search by bilingual name, category, and subcategory. Search starts in plain-text mode and its adjacent anchored regex builder provides the full construction workbench.

Portable by design

Schema 3 stores only validated public identity and display copy. It omits response bytes, photo bytes, browser cache, request progress, credentials, provider sessions, machine paths, process state, and host identifiers. Import performs no network request, process launch, provider mutation, or deployment.

Progress and recovery

Catalog loading reports measured bytes or percentage, supports cancellation, and exposes retry after a failure. A failed published photo keeps the selected bilingual details visible and provides a dedicated photo retry. An existing selection remains intact when a refresh fails.

Public source

Catalog metadata and photos come only from Ding-Ding-Projects/dim-sum-photos and its published releases. No photo is copied into this project or its installer.

Verification status

This ultra-speed source lane ran no tests, type checks, lint, builds, packaging, runtime interaction, audits, reviews, or captures.
