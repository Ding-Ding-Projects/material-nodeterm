Releases

Packaging & auto-update

Windows builds ship as an unsigned Squirrel set: Setup.exe, RELEASES, and a full package. The current stable release is v0.4.117, published 2026-08-26 from commit 727287b8eddd5c30f98306ea442a2584945668d0. The installed app checks the stable GitHub Release in the background and never interrupts active work.

Behaviour

Windows uses Electron's built-in Squirrel updater. While a newer package downloads, the minimizable card shows an indeterminate state because Squirrel does not expose byte progress. Once ready, Restart to update is your explicit way to restart immediately and can run only once. A downloaded update may instead apply on the next normal app launch even when that button is unused. macOS and Linux deliberately retain their existing updater path.

Current Squirrel release

The published Windows release contains the complete Squirrel set for v0.4.117: nodeterm-Setup-0.4.117.exe, RELEASES, and node-terminal-0.4.117-full.nupkg. The release is non-draft and non-prerelease. Older NSIS-only migration wording is historical and is no longer the current update route.

Release channel

The stable feed is the project's latest GitHub Release asset root. The release workflow runs for every push to the main branch and for workflow_dispatch, and it accepts only the main branch for a stable publication. Feature-branch and prerelease builds do not belong in the stable feed. The workflow builds and packages the unsigned Squirrel set, then publishes one uniquely versioned release after the required asset checks.

Failure modes

If the feed is offline or returns 404, nodeterm keeps the installed version running and retries scheduled checks normally. A check you request reports the error without blocking the app; it never turns a failed read into “no update exists.” Duplicate checks and restart requests are coalesced.

Security considerations

The Windows installer and updates are intentionally unsigned. Verify the GitHub Release's target commit, hashes, and complete Squirrel asset set. The updater delegates RELEASES selection to Squirrel instead of fetching a second policy copy that could disagree at install time.

Surface scope

The Server Edition has no desktop installer, and the separately maintained mobile companion does not consume Squirrel packages. This Windows desktop updater is therefore not applicable to those surfaces.

Verification status

Deterministic checks cover feed selection, version advancement, wrong-channel diagnostics, failure degradation, and one-shot immediate restart. The v0.4.117 release metadata and complete Squirrel asset set are verified. A separate real-installed-app transition run is still required to prove update discovery, download, restart, and settings persistence end to end; this page does not claim that runtime proof has completed.
