AWS service managers

The AWS Universe includes typed managers for S3, EC2, IAM, STS, Lambda, CloudWatch, and Logs. Each operation uses a guided form and the shared schema executor. There is no raw shell or raw request editor fallback.

What the managers provide

  • Searchable operation catalogs with typed enums, switches, bounded numbers, date-time controls, and native file pickers.
  • Permission checks before execution, exact disabled-state reasons, and retry handling limited to transient service failures.
  • Bounded pagination, waiters, streaming, progress, cancellation, and per-item bulk outcomes.
  • Destructive previews with exact affected resources and a single-use expiring confirmation.
  • Portable intent that omits profiles, credentials, tokens, local file handles, caches, and host paths. Import does not call AWS.
