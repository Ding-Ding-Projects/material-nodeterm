Integrations

Cloudflare manager

The manager provides guided account, zone, DNS, SSL/TLS, ruleset, redirect, cache and analytics controls through Cloudflare's documented v4 REST API.

Behaviour

Accounts and zones are discovered with page metadata. DNS, ruleset and redirect lists are searchable. Every mutation uses a typed form. Destructive deletion and cache purge show a fresh reviewable preview before the request is sent.

Local token storage

The API token is entered through a password field and stays in the local credential vault. It is never included in a project export, renderer payload, log, or documentation record. A partial local snapshot retains only non-secret successful results.

Failure modes

Not configured, unauthorized, forbidden, rate limited, unreachable, invalid response, oversized response, and missing resource states remain distinct. Rate-limit retry timing is bounded and provider error text is redacted.

Portability and security

Project import performs no provider request or mutation. Cloudflare bindings, credentials, caches and runtime identifiers remain local, so another computer offers Configure or Leave Unbound instead of silently adopting an account.

Verification

This implementation lane intentionally did not run tests, type checks, linting, security checks, builds, packaging, installer execution, runtime interaction, or UI captures. Those checks remain required before a release claim.
