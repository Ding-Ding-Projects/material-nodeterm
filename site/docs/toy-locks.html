Toy locks

Lock any of this site's own panels behind a password — just for fun, never for security. Each lock has its own independent credential; there is no master password.

Behaviour

Two of this site's own panels — Personal vocabulary and Narrator — are wired as real lockable surfaces, demonstrating the mechanism concretely rather than as a list that only manages itself. A locked, not-yet-unlocked surface stays honest in search: it's still reachable, and opening it shows a plain unlock prompt rather than doing nothing or pretending the surface doesn't exist.

Configuration

Locks are tracked as a real, enumerable, individually removable list with its own search — multi-select several at once to re-lock or remove them in bulk.

Failure modes

Forgetting a lock's password is recovered the same way as School mode's PIN: clearing this site's browser storage removes every lock along with everything else — stated directly on every unlock prompt.

Security considerations

This is explicitly not a security boundary and never claims to be — it does not protect, secure, or encrypt anything, at any funny level. Password verification uses crypto.subtle against a per-lock stored hash, never a stored plaintext password.

Verification

Unlocking a session is intentionally not persisted — a page reload re-locks everything, which is the honest behaviour for a toy lock with no real session concept.
