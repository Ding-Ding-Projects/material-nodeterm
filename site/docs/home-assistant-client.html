Home Assistant multi-instance client

A Home Assistant service node can register several machine-local instances, bind one explicitly, and discover current entities through the REST API or Home Assistant WebSocket API.

Guided operation

  1. Add an instance with a display name, HTTPS address, and long-lived access token.
  2. Filter the instance picker with plain text or its anchored regex builder, then bind the selected instance.
  3. Choose REST or WebSocket discovery. Progress, cancellation, retry, and exact recovery messages remain in the node.
  4. Filter discovered domains and entities with their independent search and regex controls.

Privacy and portability

The address, instance id, access token, request state, socket, and entity cache remain on this computer. Schema 3 carries only the node label, layout, relationships, discovery preference, and domain preference. Import makes no network request and leaves the node explicitly unbound until Configure or Rebind is chosen.

Failure behavior

Requests refuse redirects and oversized responses, have a bounded deadline, preserve prior results after cancellation or failure, and distinguish token refusal from unavailable metadata or malformed provider responses. Removing an instance uses the two-key confirmation flow and clears its stored token.
