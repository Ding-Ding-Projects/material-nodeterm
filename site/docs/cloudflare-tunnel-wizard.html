Remote and services

Cloudflare Tunnel wizard

The one-click wizard presents populated choices for a Cloudflare account, zone, hostname, origin host, discovered container, network, port, and verified origin. It is review-first: the user sees the exact route before any external operation starts.

Guided controls

Every picker has its own local plain-text search and adjacent anchored regex builder. The host boundary receives opaque selections from the latest discovery snapshot, not a raw request, shell command, container command, or arbitrary origin URL. The hostname is validated as a DNS name inside the selected zone.

Progress and recovery

Creation reports preflight, creation, routing, verification, completion, cancellation, and failure. Cancellation uses a bounded abort path and preserves the prior binding. A failed operation retains its review so the user can refresh discovery or retry without re-entering the choices.

Privacy and portability

Portable schema 3 keeps the requested hostname, zone name, protocol, port, and desired host, container, and network labels. Account ids, zone ids, host ids, container ids, network ids, credentials, paths, caches, and process state remain local. The trusted host stores a provider-account reference and a stable local vault-key name, never the credential value.

Verification

This ultra-speed implementation lane did not run tests, type checking, lint, review, security or accessibility checks, builds, packaging, installer execution, runtime interaction, or captures. Provider adapter wiring and runtime evidence remain for the integration and verification lanes.
