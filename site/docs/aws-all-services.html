AWS Universe

Generic AWS all-service interface

The AWS service node reads the installed AWS CLI model inventory. Newly installed services, commands, and input shapes appear through the same typed interface without a new hand-written form.

Guided controls

Services, commands, profiles, regions, waiters, and modeled enum values are searchable pickers. Every search has its own adjacent anchored regex builder. Structures, lists, maps, booleans, numbers, timestamps, and local files use controls matched to their shape. Unsupported model data stays visible as an honest unavailable state.

Review and execution

Before execution, the node shows the service, command, account, role, region, endpoint, pagination, waiter, retry, streaming, output mode, generated argument vector, risk, and portable omissions. The privileged host regenerates the argument vector from the current model and invokes the bundled CLI without a shell. Destructive operations use the existing two-key confirmation surface. Progress, cancellation, partial results, and errors remain visible in the node.

Portability

Project files contain safe service intent only. Profiles, credentials, account sessions, role bindings, endpoints, selected files, CLI paths, and result data stay local to the host. Import performs no provider call and leaves local configuration to an explicit user action.

Honest limits

The implementation lane intentionally did not run tests, type checks, lint, security or accessibility checks, builds, installer execution, runtime interaction, or captures. Those checks remain release work rather than being implied by this documentation.
