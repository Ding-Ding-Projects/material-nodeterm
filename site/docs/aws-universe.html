Canvas

AWS Universe portal

Each AWS Universe portal opens an AWS-only child canvas. Instances are direct children of the project root, have no product depth ceiling, and begin with one permanent scoped Shop.

Create and navigate

Use the canvas app-bar navigator to search instances or choose New AWS Universe. Names are required. Plain text is the default search mode, and the search field has its own anchored full regex builder. A portal card opens the selected child canvas.

Portable intent

Schema 3 preserves the safe instance name, id, order, viewport, node intent, Shop metadata, and relationships. Credentials, profiles, role sessions, CLI paths, local files, process state, caches, and account bindings stay local. Import reconstructs data without contacting AWS or launching anything.

AWS-only scope

The portal and its Shop carry an explicit AWS-only scope. Non-AWS catalog rows are not offered by this route, and stale selections are revalidated before creation.

Verification boundary

Issue #39's ultra-speed implementation lane intentionally did not run tests, type checks, lint, reviews, security checks, accessibility checks, builds, packaging, runtime interaction, installer execution, or captures.
