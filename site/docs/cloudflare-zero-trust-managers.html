Integrations

Cloudflare Access, Zero Trust, Workers, Pages, R2, D1 and Queues

This canvas manager is a guided client for the documented Cloudflare API. It is not a raw request editor, arbitrary shell, or hosted substitute for the installed app.

Guided typed operations

Seven fixed manager families expose typed list, create, deploy, remove, and purge actions. Account, operation, and verified-resource pickers are searchable, keyboard-operable, and each has its own adjacent anchored regex builder. Workers deployment uses a selected local script file and never accepts a command or remote URL.

Local credentials and portable intent

API tokens, account ids, credential references, resource ids, selected file paths, response caches, and progress state stay in local protected storage. Schema 3 carries only neutral manager, operation, and field intent. Import has no network, deployment, process, or file-selection side effect, so a new computer visibly remains unbound until configured.

Bounded and reviewable execution

The trusted core owns fixed HTTPS routes, rejects redirects, bounds responses to 8 MiB, enforces a 60-second deadline, redacts result previews, and aborts cancellation. Destructive actions require the app's existing two-key confirmation and a complete preview before any request is sent. Progress, failure, cancellation, and partial result states remain visible.

Implementation status

The implementation is in src/shared/cloudflare-zero-trust.ts, src/core/cloudflare-zero-trust/service.ts, and src/renderer/components/cloudflare/CloudflareZeroTrustPanel.tsx. This ultra-speed lane intentionally ran no tests, type checks, lint, reviews, security or accessibility checks, builds, packaging, installer execution, runtime interaction, or UI captures. The parent integration lane must provide those verdicts.
