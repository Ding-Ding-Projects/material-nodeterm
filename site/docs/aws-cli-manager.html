Integration

AWS CLI v2 manager

The desktop and Server Edition surfaces provide a Windows x64 AWS CLI v2 manager. It installs for the current user, verifies the exact AWS installer bytes, and discovers Bedrock foundation models through the installed CLI.

Verified installation

The pinned AWS CLI release is 2.36.31. The manager checks the packaged user MSI first, then fetches the same version from the official AWS endpoint only when the packaged resource is unavailable. The expected SHA-256 is 300d490cebe7d89913acc0f7ca1c585032fd2a7f698e809d7ce9905614013acd. A mismatch, failed installer, cancellation, or wrong post-install version leaves the prior valid installation in place and reports the recovery action.

Resolution is limited to the app-owned versioned cache and AWS's documented current-user location under %LOCALAPPDATA%\Programs\Amazon\AWSCLIV2. PATH is not used as authority, and the installer never asks for administrator access.

Offline model inventory

The Foundation models tab runs aws bedrock list-foundation-models --output json --no-cli-pager through the privileged host process. It shows model id, name, provider, modalities, streaming support, customizations, and inference types. A bounded local cache preserves the last verified result when AWS or the CLI is unavailable, and the UI marks it stale rather than presenting an empty or guessed inventory.

Search and recovery

Model search is plain text by default and has an anchored regex builder for deliberate pattern searches. Install, repair, refresh, and cancellation are non-blocking actions with progress and exact error details. Credentials and environment values are not returned, cached, logged, or included in exports.
