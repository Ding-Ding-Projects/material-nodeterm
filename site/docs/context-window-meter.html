Agents

Context-window meter

Every agent card carries a context-window progress track at its top edge, including resumed, grouped, minimized, restored, kanban, custom, and ephemeral subagent cards.

Provider sources

Claude Code reads assistant transcript usage and its model-family window. Codex reads last_token_usage.input_tokens with model_context_window. Gemini reads transcript tokens.input and its model-window resolver. Grok, opencode, custom agents, and ephemeral subagents remain explicit when no verified used and total pair exists.

Honest states

Known cards show used, total, remaining, and percentage. Other cards say unknown, not reported, stale, or unavailable. Healthy, warning, and critical threshold text accompanies the bar, so colour is never the only signal.

Local and bounded

Provider and source identity are part of the cache key. Producer epochs and lifecycle generations reject delayed readings, including readings from older lifecycles. Session locators use bounded indexes, remote deltas require a verified byte-size cursor and capped reads, and context telemetry stays in local application data rather than shared project files or exports.

Epochs use ordered producerId:lifecycle identities, not random per-reading values. A fresh producer may restart at generation one, while retired producer and epoch identities are rejected. Legacy cache records keyed only by a bare session id are discarded and never used as a runtime fallback. Remote retracking compares the host, port, ControlMaster path, transcript path, identity file, extra SSH arguments, and trusted-execution provenance.

The collapsed subagent minimum is calculated from its rendered context strip, header, task line, and metadata line, so resizing cannot hide the identifying content.

Accessibility

The progress track exposes an accessible value when numbers are known and a textual state when they are not. The detail surface is measured against the live anchor, chooses the available side without covering the initiating control, and respects reduced motion and narrow layouts.
