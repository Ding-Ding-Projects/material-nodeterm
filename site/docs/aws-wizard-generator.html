AWS tools

AWS wizard generator

The AWS wizard is a schema-driven canvas node for composing and reviewing an AWS request shape locally. It never executes a provider request.

Typed controls

A model schema becomes searchable enum choices, switches, bounded number controls, native date and time fields, local file pickers, repeatable lists and maps, and nested object editors. Every field has a description and inline validation. Add controls state their collection limit instead of silently doing nothing.

Advanced views

JSON and YAML are synchronized views over the same value object. Applying either format parses a bounded object and validates it against the same schema as the typed controls. The advanced editor is not an arbitrary command box and does not launch a shell.

Portability and privacy

The schema and safe request intent travel with the project. A selected local file path stays in the local browser or desktop state and is never written into the shared project projection. Importing a request performs no network call, deployment, provider mutation, process launch, or download.

Failure recovery

Malformed or oversized JSON/YAML, unknown keys, unsafe map keys, invalid dates, and out-of-range numbers remain visible as inline errors. The last accepted values stay in place until a valid replacement is applied.
