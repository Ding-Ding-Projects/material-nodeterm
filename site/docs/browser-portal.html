Browser

Browser Portal

Browser Portal is the canvas browser node with guided isolated profiles and explicit lifecycle ownership. It is a real embedded browser surface, not a shell command runner.

Profiles and navigation

Create and rename profiles from the browser header picker. The picker keeps a local search field beside its anchored full regex builder. A profile name and selected tab are safe project intent. Cookies, site storage, cache, extension directories, process handles, and other browser session data remain local to the computer.

Nodes using one profile share its local session. Different profiles use different persistent Electron partitions. User navigation belongs to the visible node, while agent control is a separate, revocable lease.

Close and reset

Closing the final tab resets a regular node to one blank tab. Temporary popup nodes are not saved unless the user chooses Keep. Reset profile uses the two-key confirmation surface and clears cookies, site storage, cache, and loaded unpacked extensions while retaining the profile name and project tab list. Removing a profile removes only its project label, so existing nodes never silently merge into the shared session.

Portability and boundaries

Import and export carry node identity, URL, tab order, active tab, and profile selection intent. They never carry credentials, browser storage, machine paths, extension paths, process state, or debugger handles. Import does not navigate, download, launch, or mutate a provider.

Server Edition can preserve browser intent, but its visitor browser storage is controlled by the visitor's browser and cannot clear an Electron partition. The mobile companion has no embedded Electron session and must show an explicit unsupported state. Electron extensions are unpacked-only and expose a subset of Chrome APIs.

Verification

This implementation lane intentionally did not run tests, type checks, lint, security or accessibility checks, builds, packaging, installer execution, runtime interaction, or captures. Those checks remain an independent verification lane.
