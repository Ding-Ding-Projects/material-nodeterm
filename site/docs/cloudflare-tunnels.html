Remote & SSH

Cloudflare tunnel manager

Inspect Cloudflare control-plane state from Settings → Cloudflare tunnels. This surface does not run a connector runtime.

Inventory and status

Inventory reads accounts, zones, tunnels, connections, routes, and DNS records through the privileged core. Token state is presence-only. Unauthorized, partial-permission, rate-limited, and unreachable states stay distinct.

Typed configuration preview

Routes use guided hostname and HTTP(S) service fields. Every write previews its exact changes, preserves unmanaged routes, and blocks duplicate or conflicting hostnames before the API mutation.

DNS adoption proof

DNS adoption requires an existing CNAME in the selected zone that points to a Cloudflare tunnel hostname. The preview shows the zone and record proof. Adoption records the local relationship and never replaces or deletes an unmanaged record.

Local binding and limits

Account, zone, tunnel, and hostname intent is bound to this computer in local application data. Credentials, machine identity, provider sessions, caches, and connector process state are not portable. The implementation lane intentionally does not launch cloudflared.

Verification boundary

This ultra-speed implementation lane did not run tests, type checks, linting, security checks, accessibility checks, builds, packaging, installer execution, runtime interaction checks, or UI captures. The source and documentation describe the shipped boundary, not a claim that those checks ran.
