Converter pipelines

Bounded, offline conversion

This documentation page describes the installed converter. It is not the converter runtime: use the desktop or Server Edition surface for real files.

Available now

  • Images: bounded PNG, JPEG, WebP, GIF, BMP, ICO, SVG, and HEIC re-encoding through the bundled sharp codec.
  • ZIP: safe creation and extraction with relative names, duplicate rejection, symlink refusal, entry limits, expanded-byte limits, and atomic output.
  • PDF: bounded signature, page, title, author, and selectable-text reports. Scanned pixels require OCR.
  • Structured data: JSON Lines and NDJSON transforms, alongside JSON, YAML, TOML, XML, CSV, and TSV.

Disabled capabilities stay visible

OCR, audio/video transcoding, PDF split, merge, rotation, and rasterization, TAR, and 7-Zip remain listed with their exact missing verified dependency. The app never searches PATH, sends files to a network service, accepts arbitrary shell text, or claims that an unverified tool is bundled.

Progress and recovery

Advanced jobs persist locally with a schema version, bounded concurrency, stage-labelled byte progress, pause, cancellation, retry, and crash recovery. Every output is validated, hashed, written atomically, and shown with its real path and byte count. Lossy operations disclose pixel, metadata, animation, scan, or structure loss before conversion.

Security boundary

Native tools are selected from a fixed allowlist, checked beneath the app's private converter-tools directory, optionally verified by SHA-256, launched with an argv array and no shell, and given a scrubbed environment plus time and output limits. Credentials and private file contents never enter queue records or exports.
