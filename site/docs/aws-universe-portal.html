AWS Universe portal

An AWS Universe is an unlimited-instance, AWS-only canvas portal. Each instance has a matching entry door and return door, safe portable intent, and a searchable catalog of AWS interfaces.

Door-only scope

Choose Enter through matching door to enter the AWS-only canvas. Choose Return through matching door to leave it. Ordinary tab navigation cannot bypass either door. The portal does not call AWS, deploy resources, download data, or launch a process.

Portable and local data

The project carries the universe id, display name, AWS-only scope, region or service intent, and deterministic door ids. Credentials, provider sessions, profile bindings, paths, process state, caches, and host identifiers stay in the machine-local context namespace nodeterm.aws-universe.local-contexts.

Import and relaunch validate the portable metadata and produce a Configure, Rebind, or Leave Unbound plan. Import has no external side effects.

Catalog interfaces

The catalog search is plain text by default and has an adjacent anchored regex builder. AWS Shop, service, and operation entries remain visible with exact disabled reasons because those operations belong to later lanes.

Verification boundary

The ultra-speed implementation lane did not run tests, type checks, lint, review, security checks, accessibility checks, installer execution, runtime interaction checks, or UI captures. Build and packaging evidence proves artifact production only.
