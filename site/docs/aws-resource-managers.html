AWS resource managers

The AWS resource-manager node provides guided ECR, ECS, EKS, RDS, database-family, VPC, Route 53, and cost workflows. It is a documentation and download surface, not the installed desktop runtime.

Guided operations

Typed fields, bounded numeric controls, allowlisted choices, searchable resources, progress, cancellation, partial results, retry, and recovery guidance replace raw commands and raw request editors. Each search field keeps plain text as the default and exposes its adjacent regex builder.

Portable intent

Portable project data records only safe manager and operation intent. Credentials, account sessions, endpoints, live resource identifiers, job state, and provider caches remain local. Import performs no AWS request or resource mutation.

Availability

When the local AWS adapter is unavailable, the node remains visible and names the exact next action. An unavailable adapter is not presented as an empty successful resource list.

Verification boundary

Issue #49 is an ultra-speed implementation lane. Tests, lint, type checks, reviews, security and accessibility checks, builds, packaging, installer execution, runtime interaction, and UI captures were intentionally not run. The integration lane owns those later proofs.
