AWS core-service managers

The desktop canvas manager provides typed, reviewable operations for S3, EC2, IAM, STS, Lambda, CloudWatch, and CloudWatch Logs. It uses the local AWS CLI through the application host and never accepts arbitrary shell commands or raw request editors.

Services and operations

  • S3: list buckets, list objects, create bucket, delete bucket.
  • EC2: describe instances and security groups, start, stop, and terminate instances.
  • IAM: list and inspect users and roles, create users, and delete users.
  • STS: inspect caller identity without exposing session credentials.
  • Lambda: list, inspect, and delete functions.
  • CloudWatch: list metrics and request metric data.
  • CloudWatch Logs: inspect groups and streams, read events, and filter events.

Portability and privacy

Project files carry only the service, operation, region intent, and safe fields. Profile, endpoint, account session, command output, process state, and credentials remain local. Import performs no provider request or process launch.

Verification status
