AWS

AWS core-service managers

The AWS Shop exposes S3, EC2, IAM, STS, Lambda, CloudWatch, and CloudWatch Logs through the existing AWS manager node and shared AWS CLI service. Each operation is typed, previewed, and bounded. There is no raw shell or arbitrary argument editor.

Guided operations

  • S3: list buckets and objects, create buckets, and delete buckets.
  • EC2: describe instances and security groups, start, stop, and terminate instances.
  • IAM: list and inspect users and roles, create users, and delete users.
  • STS: get caller identity only. Session credentials are never returned to the renderer.
  • Lambda: list, inspect, and delete functions.
  • CloudWatch: list metrics and request metric data.
  • CloudWatch Logs: inspect groups and streams, read events, and filter events.

Portability and privacy

Project data stores only safe AWS mode, service, operation, region intent, and typed input. Profiles, endpoints, sessions, request tokens, results, CLI paths, process state, and credentials remain local. Import performs no provider request or process launch.

Verification

This implementation lane has not run tests, builds, packaging, runtime interaction, reviews, accessibility or security checks, or captures. Those Chuts remain pending for integration.
