Cloudflare Tunnel state

The tunnel state surface reports six independent observations instead of one optimistic connection flag.

  1. API creation
  2. DNS routing
  3. Connector health
  4. Access policy
  5. Origin reachability
  6. External reachability

Honest state

Each observation carries its own timestamp, bounded detail, and recovery reason. The states are unknown, pending, ready, failed, and blocked. Unknown means no trustworthy observation exists. The overall route is ready only when all six facets are ready.

Portability and local state

Schema 3 carries safe route intent such as the hostname, origin port, connector mode, access-policy intent, and route mode. Provider ids, credentials, connector ids, process state, local paths, and live observations remain on the local computer. Import does not contact or mutate a provider. Configure or Rebind is required on the destination computer.

Guided controls

The state panel provides local plain-text search and a separate status filter. Each field has its own adjacent anchored full regex builder. Retry is offered only where a new check is meaningful, and disabled controls explain the exact reason.

Verification

The ultra-speed implementation lane did not run tests, type checking, lint, review, security or accessibility checks, builds, packaging, installer execution, runtime interaction, or captures. This article records source intent, not runtime verification.
