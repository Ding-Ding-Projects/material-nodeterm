Portable media assets

Schema 3 project saves carry validated project-owned media by SHA-256 content address. Local source paths, credentials, provider state, and process state stay on the source computer.

Three explicit choices

  • Include copies validated bytes into the portable archive.
  • Omit leaves bytes out and records the user's choice.
  • Locate Later records an unresolved placeholder so another computer can choose the file explicitly.

Validation

Collection checks a regular file, bounded bytes, known signatures, normalised MIME and extension, and SHA-256. Import checks schema 3, content addresses, labels, media kinds, and dimensions or duration bounds. Invalid or unsupported media is refused or recorded as an omission, never partially applied.

Privacy and side effects

Import makes no network request, deployment, process launch, download, or provider mutation. Source paths are used only by the local picker. The guided picker has plain-text search and an adjacent anchored regex builder, accessible decision buttons, and an honest no-match state.

Implementation and verification

The contract is implemented in src/core/portable-media-assets.ts, with schema 3 projection support in src/core/portable-canvas-projection.ts and the guided renderer in src/renderer/components/PortableMediaDecisionDialog.tsx. This lane did not run tests, builds, packaging, runtime interaction, or captures; archive wiring and built-artifact evidence remain pending.
