Canvas

Special-universe Shop nodes

Each Multiverse or AWS Universe child canvas owns exactly one Shop. The root canvas has no Shop. This card is the scope-bound catalog entry point, not a provider session or a network connection.

Behaviour

The deterministic id is shop-<canvas-id>. Import, hydration, undo replay, and peer retries all use the same idempotent coordinator. A missing Shop is rebuilt, duplicates are reduced to the deterministic record, and a Shop in an invalid scope is removed from that scope with a repair record.

Scope

  • Multiverse: general terminal, sticky note, editor, browser, and authenticator entries, plus another portal while depth remains below 8.
  • AWS Universe: AWS identity, Resource Explorer, Cloud Control, S3, EC2, IAM, STS, Lambda, CloudWatch, CloudWatch Logs, CloudFormation, CDK, ECR, ECS, EKS, RDS, databases, VPC, Route 53, cost management, and the generic installed-model operation wizard. Entries whose executor belongs to a later lane remain visible as unavailable with an honest reason.
  • Root: no Shop and no universe catalog.

Fixed actions

A Shop cannot be deleted, duplicated, moved across canvases, grouped, or removed or restored by ordinary undo. The same refusal applies to peer mutations. Nodes created from the Shop remain ordinary user-owned nodes.

Accessibility and search

The card has a labelled local search field, a result count, keyboard-operable entries, visible focus, and an anchored full regex builder beside the field. The AWS list is an explicit scope projection, and each selection is revalidated before it reaches the live creation coordinator. The card uses the shared English, playful Hong Kong-style Cantonese, and bilingual language catalogue with the project Material Design 3 tokens.
