Dim sum surprise

A 10% chance, on every page load, of a small dish appearing in the corner — named in both languages, illustrated with a small original SVG drawn for this site. There is no setting anywhere that turns it off.

Behaviour

Non-blocking and auto-dismissing: it never gates the page loading, never steals keyboard focus, and never appears twice in one load. The draw happens exactly once, deferred slightly so it never competes with the very first paint.

Configuration

There is deliberately no configuration for the random draw itself — the Dim Sum panel only offers a manual "show me another dish" peek button, which is a convenience for browsing the catalog, not an opt-out of the automatic surprise.

Failure modes

Suppressed entirely while School mode is on, per that feature's "behave as if not installed" contract.

Security considerations

All six dish illustrations are original SVGs bundled with this site — nothing is fetched from a third party or a CDN.

Verification

The roll is a single Math.random() call per page load, in site/app/features/dimsum.js's maybeShowDimSumSurprise(), which itself only ever runs once per load.
