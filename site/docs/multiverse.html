Multiverse child canvases

A Multiverse child canvas is scoped content inside one project. It is not a project and never appears as a project tab.

Hierarchy

The stable root identity is root. Each child carries its own identity, parent identity, depth, viewport, and node content. Nesting is bounded at depth 8, with missing parents, cycles, duplicate identities, and depth mismatches rejected.

Portable and safe

Schema 3 projection preserves child content and relationships while omitting credentials, host identifiers, process state, and machine-local execution values. Import validates the complete hierarchy before adopting anything and performs no external side effect.

Canvas scope

The canvas command palette and app bar open the Multiverse navigator. Its searchable list has an adjacent anchored regex builder, a guided parent picker, depth-aware disabled reasons, and a catalog summary. Commands address the active canvas scope, and nodes cannot cross child-canvas boundaries.

Door construction, code entry, and the recovery game are intentionally reserved for later Wave D features.
