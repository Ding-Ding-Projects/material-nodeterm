Nextcloud AIO hosting

Nextcloud AIO is a guided, private-first hosting profile. It uses the pinned official nextcloud/all-in-one:2025.8.0 image through a selected Docker context and does not accept arbitrary images, shell commands, Compose text, or free-form environment values.

Guided controls

The node provides a Docker-context picker, loopback or private-network binding, a bounded port field, and explicit Deploy, Start, Stop, Update image, Create backup, Restore, and Rollback actions. Queued, running, completed, failed, and cancelled progress is shown at the node that started the operation. Context and backup searches are independent plain-text fields with adjacent anchored regex builders.

Docker authority and safety

The AIO master container needs Docker control to supervise its child containers, so the profile mounts the Docker socket read-only. The node says plainly that this socket can control the Docker host and is not a security boundary. The fixed invocation uses no-new-privileges, drops capabilities, uses a read-only root filesystem, and never passes --privileged.

Portability and recovery

Schema 3 carries only safe image, binding, port, and profile intent. Context names, endpoints, socket paths, container ids, volume contents, backup records, process state, host paths, and credentials remain local. Import has no external side effect. Missing Docker, vanished contexts or backups, invalid ports, and failed operations remain distinct and name their refresh or retry route.

Verification

This ultra-speed implementation lane did not run tests, type checking, lint, review, security or accessibility checks, builds, packaging, installer execution, runtime interaction, or captures. Later verification must use the exact integrated commit.
