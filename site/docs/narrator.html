This site

Narrator

A spoken narrator built on the browser's own speech synthesis, off by default. Language choice is English, Cantonese, or Both — where Both speaks English then Cantonese strictly serialized, never overlapping.

Behaviour

Two independent voice pickers — one per language — because choosing an English voice says nothing about which Cantonese voice should read the other half of a bilingual line. Each picker lists only the voices actually installed for that language on this machine, plus an explicit "choose automatically" option, which is the shipped default.

Configuration

Rate and pitch sliders adjust delivery within the platform's supported range. If a previously chosen voice is no longer installed, the choice is kept (never silently reset) and the narrator falls back to another voice for that language until the original one reappears.

Failure modes

The browser's voice list commonly arrives empty on the very first call and fills in a moment later behind a voiceschanged event — every picker on this site subscribes to that event and re-reads the list rather than reading it once and reporting "no voices installed" on a machine that has forty of them.

Security considerations

Speech synthesis runs entirely through the browser's own API; nothing spoken is sent anywhere.

Verification

Utterances are pushed through a single shared queue so "Both" can never speak English and Cantonese at the same time — see the queue in site/app/features/narrator.js.
