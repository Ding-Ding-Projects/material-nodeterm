Files and media

Advanced media pipelines

Advanced media is a separate queue for operations that create several outputs, write a destination folder, or need a bounded local process. The express converter remains the route for one-input/one-output structured, text, binary, gzip, and Brotli conversion.

Built-in operations

  • Inspect PNG, JPEG, GIF, WebP, BMP, and ICO headers, including dimensions and MIME type.
  • List, create, and safely extract ZIP and TAR archives.
  • Inspect PDF page counts and encryption, then extract conservative text from unencrypted files.

Verified external tools

Media stream probing and OCR are enabled only by a package-owned manifest containing an HTTPS source, version, executable name, and SHA-256. The app never searches PATH or accepts an arbitrary command. Each child runs with shell execution disabled, a reduced environment, bounded arguments and output, a deadline, and cancellation.

Safety and progress

Archive traversal, absolute paths, links, duplicate entries, oversized data, malformed headers, and existing destinations are refused. Outputs are validated before atomic publication. Every job reports reading, processing, writing, validation, completion, cancellation, and failure with byte counts and a partial-result state.
