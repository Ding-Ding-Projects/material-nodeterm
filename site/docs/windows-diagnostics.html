Windows

Read-only Windows diagnostics

The Windows diagnostics canvas node shows a bounded snapshot of drives and storage, services, startup entries, scheduled tasks, updates, network state, and System/Application event summaries.

Guided, read-only surface

Each area has its own tab and a local plain-text-first filter with an adjacent anchored full regex builder. The node offers refresh and rename only. It never starts, stops, enables, disables, edits, deletes, installs, or restarts a host resource.

Honest host states

Non-Windows hosts report that the capability is unavailable. Missing providers, failed fixed queries, empty results, and malformed responses stay distinct. Raw event messages are not collected; event data is summarized by log, level, provider, event id, and count.

Privacy and portability

The trusted core runs one fixed read-only PowerShell script with a fifteen-second deadline and bounded output. Snapshot rows, host identifiers, paths, process state, caches, and query output remain local runtime data and do not enter portable project files.

Verification

This ultra-speed implementation lane did not run tests, type checking, lint, review, security or accessibility checks, builds, packaging, installer execution, runtime interaction, or captures.
