School mode

A user-experience lock, not a security boundary. Turning it on forces English and makes the Cantonese, bilingual, funny-level, and dim-sum-surprise controls behave as if they were never installed at all.

Behaviour

While on, the language-mode radios, both funny-level sliders, and the dim-sum surprise are hidden entirely rather than merely disabled — this site's other feature modules check School mode's state on every render and simply don't build that part of their UI when it's active. Turning School mode off requires a PIN, verified against a locally stored hash; the PIN itself is never stored anywhere.

It's user-renamable. After a rename, the shipped name "School mode" is never shown again anywhere on the site — every surface reads the current, live display name rather than a cached copy of the original.

Configuration

Set a PIN before turning School mode on for the first time — there's no way to turn it back off without one, aside from the recovery route below.

Failure modes

Forgotten the PIN? Clearing this site's browser storage (your browser's "clear site data" for this page) resets School mode along with every other setting on this page — that route is stated directly on the control itself, every time it's shown.

Security considerations

This is explicitly not security. It never claims to protect, secure, or encrypt anything, at any funny level — it's a self-imposed speed bump, exactly like a parental-control toggle that the same person who set it can always remove.

Verification

The PIN is checked with crypto.subtle against a stored hash, never against a stored plaintext PIN — inspectable directly in site/app/shared/school-state.js.
