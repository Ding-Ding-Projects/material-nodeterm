Canvas

Unified Node Catalog

The FAB, empty-canvas context menu, and command palette share one typed registry and creation coordinator. Existing shortcuts and file drops remain fast paths into the same intent model.

Behaviour

Rows carry stable ids, categories, keywords, documentation links, dependency ids, safe defaults, and availability facts. Unavailable rows remain visible with the exact next action. Home Assistant controls and sensor displays are available with portable intent and machine-local bindings; planner, Multiverse, AWS, and hosting blueprints remain explicit disabled rows. A selected row receives one immutable creation event id. Retrying that id is idempotent, and collision-free placement finds the next free rectangle rather than piling nodes together. If the bounded search is exhausted, creation is refused and the canvas stays unchanged.

Interaction

The dialog has category chips, a bounded keyboard-navigable list, result counts, visible focus, and a search field with its adjacent anchored full regex builder. Plain text is the default. Up and Down choose, Enter creates, and Escape clears before closing. Documentation actions open the bundled in-app reader rather than a raw relative Markdown URL.

Portability and safety

Safe defaults are project intent. Credentials, sessions, process state, host identifiers, and absolute machine paths stay local. Hydrating a saved project remembers event ids without creating new events or launching any process.

Verification

The implementation pass intentionally did not run tests, type checks, lint, security checks, accessibility checks, builds, packaging, installer execution, runtime interaction, or captures. Build and packaging evidence proves artifact production only.
