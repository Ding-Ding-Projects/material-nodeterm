Cloudflare Tunnel inventory

This manager reads bounded tunnel, route, and DNS inventories through the documented API. It preserves existing ingress routes and requires explicit review for hostname conflicts or DNS adoption. It is not the primary application runtime.

Guided configuration

Select an account, zone, and tunnel from the refreshed inventory, then choose a hostname, path, and origin service. The privileged host process validates each value again before sending a fixed request. Search fields are plain-text-first and each has its own anchored regex builder.

DNS adoption

Choose Adopt existing to retain a matching CNAME, Leave unmanaged to make no ownership claim, or Replace after confirmation for one exact record. Replacement requires the application two-key confirmation and the text ADOPT <hostname>. Unrelated records remain unchanged.

Portable intent and local credentials

Portable schema 3 intent contains only route presentation choices. Account, zone, tunnel, DNS ids, tokens, sessions, paths, caches, and live state remain local. Import performs no network or provider operation. Tokens are write-only and retained in the host credential boundary.
