Exports, notifications & local history

Every notification and every meaningful settings change on this site is recorded locally and stays reviewable — with full bulk-select actions — and every one of those data sets can be exported in whichever format best represents it.

Behaviour

Notifications (success/info messages, and warnings/errors that persist until dismissed) stay reviewable in a Notifications panel after they disappear from the corner toast stack. A separate Local history panel records a plain, human-readable description of every meaningful settings change — including nickname and narrator-speed changes — and keeps safe prior values so putting a change back really restores them. Appearance restores repaint the live theme and text size immediately, and putting a restore back works too. Record-only events such as exports and conversions stay labelled and do not pretend to be reversible. Authenticator deletions are also record-only because TOTP secrets are deliberately never copied into undo snapshots; deleting Time machine rows is permanent because the log cannot contain an undo copy of itself. Both confirmations say this before deletion. Deleted rows stay deleted after reload, including an explicitly empty log, and oldest entries are pruned automatically once the cap is reached.

Both lists get the full bulk-action contract: multi-select with shift-click ranges, a select-all that states what it means, inverse selection, and a reviewable count-and-preview before anything destructive runs.

Configuration

The Export panel offers your settings, notification history, and local history each in JSON, JSONL, YAML, TOML, XML, CSV, TSV, Markdown, and HTML — whichever format best fits how you want to use the data next. Authenticator secrets, toy-lock hashes, the School PIN and hidden undo payloads are not part of those export projections.

Failure modes

A format that can't faithfully represent nested data (CSV, TSV, Markdown, HTML) discloses exactly what it will flatten before the download runs, never after.

Security considerations

Nothing here is uploaded — every export is generated in this browser and handed to you as a local file download. Active TOTP records remain in their canonical browser-only store so the authenticator works, but they are never duplicated into persistent undo rows; legacy duplicates are removed and re-persisted during load.

Verification

All encoders live in one shared module, site/app/shared/exportFormats.js, so every export surface on this site uses exactly the same, single implementation of each format rather than nine slightly-different CSV writers.
