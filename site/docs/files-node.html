Canvas

Files node

A directory view that stays on the canvas beside the terminals and agents using the same folder. It is a persisted canvas object, not a replacement for the Explorer drawer.

Behaviour

Create it from the pane menu, command palette, or navigation FAB. It starts at the active project folder, or at a bound worktree folder when created inside a worktree group. The header supports collapse, colour, rename, parent navigation, refresh, and close. Breadcrumbs stay clickable at deep paths.

Search and actions

The filter uses plain text by default. Its adjacent .* control opens the full anchored regex builder with flags and validation. Rows support keyboard selection, range selection, copy-path bulk action, and drag navigation onto folders. New-file and new-folder prompts use the shared traversal-safe path validator.

Local and SSH projects

Local projects list their local session filesystem. SSH projects list the project's host through the existing SSH filesystem, while relay projects list the peer session filesystem. Remote paths never reach a local file-manager reveal action. Editor-capable files return through the shared Canvas file route.

Portability

Project files retain safe relative Files intent and presentation. Absolute paths, credentials, process state, caches, and editor applications remain machine-local. The destination resolves the path from its own project or SSH root, and import performs no external action.

Failure modes

Loading, a read failure, an empty folder, and a filter with no matches are separate states. Invalid drag data and unsafe names are ignored or rejected without partial writes. A project without a folder does not guess a root.
