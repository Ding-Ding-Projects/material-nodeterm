Integrations

Home Assistant control nodes

Create an unbound portable control, bind it to a connection stored only on the current computer, discover real entities and service schemas, and use rich domain controls or a schema-driven fallback.

Privacy and portability

Project data keeps entity, domain, and service hints. Connection ids, origins, access tokens, discovery caches, host identity, and runtime requests stay local. Import has no network, deployment, download, process, or provider side effect.

Guided controls

Connections, entities, and services each have local plain-text search and an adjacent anchored regex builder. Switch, light, fan, media, automation, cover, lock, climate, numeric, button, scene, script, vacuum, alarm-panel, humidifier, and water-heater domains receive dedicated controls. Unknown domains use fields reported by the selected service schema, with boolean, number, option, entity, target, date, time, and multiline selectors rendered as guided controls.

Recovery

Configure or rebind when local state is missing. Retry or cancel discovery after a timeout, offline response, malformed response, redirect, or size refusal. A failed call is reported as unconfirmed and never as success.

Verification boundary

This ultra-speed implementation lane intentionally ran no tests, type checks, lint, reviews, security checks, accessibility checks, builds, packaging, installer execution, runtime interaction, or captures.
