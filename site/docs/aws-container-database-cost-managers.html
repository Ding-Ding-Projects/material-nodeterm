AWS container, database, network, DNS, and cost managers

Program 38 extends the shared AWS resource manager with guided ECR, ECS, EKS, RDS, database, VPC, Route 53, and cost operations. This page documents the installed application and is not the primary desktop runtime.

One shared manager

These operations use the existing AWS resource node, local profile binding, generated previews, fixed argument arrays, bounded output, pagination, progress, cancellation, retry, and destructive confirmation. No second credential or command stack is introduced.

Portable intent

Project data retains only the selected manager, operation, region intent, and safe bounded fields. Profiles, account sessions, endpoint overrides, credentials, live resource identifiers, result rows, and process state remain local. Import performs no AWS request or mutation.

Verification boundary

This issue lane intentionally did not run tests, lint, type checks, builds, packaging, reviews, security or accessibility checks, runtime interaction, installer execution, or UI captures. Those proofs remain unverified until the owning integration lane runs them against the built application.
