Language modes, funny levels & emoji

This site's own language mode, two independent funny-level sliders, and a dialog-emoji toggle — all per-visitor, all local, all live: every other feature module on this site routes its own copy through this one.

Behaviour

Three language modes: English, playful Hong Kong-style Cantonese, and bilingual (English shown prominently, Cantonese shown as a compact secondary line, so it never crowds the layout). Two independent 1–5 funny-level sliders — one for English, one for Cantonese — because how playful you want the English to sound has nothing to do with how playful you want the Cantonese to sound.

The rule the whole feature is built around: the funny level changes voice, never facts. Every piece of copy on this site is one fixed fact string per language; a funny level only ever appends a short, clearly separate sentence after it — the fact itself is always present, verbatim, as the start of whatever gets rendered, in every category including errors and warnings. There is no exemption list.

Configuration

Set from the Language settings panel. The emoji toggle is independent of the funny-level system — it only adds a relevant, non-semantic emoji to dialog and message-box chrome, and it deliberately never touches buttons, field labels, or accessible names.

Failure modes

While School mode is on, this whole system is forced to plain English with no shaping — see the School mode article. A missing translation key logs a console warning and falls back to showing the raw key rather than crashing the page.

Security considerations

All of it is stored in this browser's own local storage; nothing is ever sent anywhere.

Verification

Because the fact string is always the untouched prefix of the shaped output, checking that the funny-level shaping never alters the fact is a matter of confirming the rendered string starts with the exact fact text at every level — a property that's checkable by inspection of site/app/shared/i18n.js.
