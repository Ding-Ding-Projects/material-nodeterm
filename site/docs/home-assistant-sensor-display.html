Integrations

Home Assistant sensor displays

Place selected Home Assistant values, binary states, enum options, gauges, trends, events, weather, calendars, and attributes on the canvas. A new or imported node starts unbound and makes no network request.

Guided binding

Configure, Rebind, and Adopt verify an instance URL and access credential on this computer. Deploy and Locate Asset stay visible but disabled with exact reasons. Leave Unbound uses the two-key confirmation and removes the local URL, sealed credential, cache, and observations.

Portable intent

Schema 3 stores entity ids, display modes, reviewed ranges, selected attributes, refresh timing, history limits, and ordinary canvas layout. Credentials, instance URLs, provider sessions, paths, host identity, cached values, and runtime state are omitted. Import causes no network, deployment, process, or download side effect.

Safety

The host-owned service rejects redirects, unsafe schemes, embedded URL credentials, oversized catalogs, and responses over 5 MB. A request has a 12-second deadline. Credentials never return to the renderer or enter exports and notifications.

Verification boundary

This ultra-speed implementation lane intentionally did not run tests, type checks, lint, reviews, security checks, accessibility checks, builds, packaging, installer execution, runtime interaction, or UI captures.
