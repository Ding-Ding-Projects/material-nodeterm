## Bundled tmux (macOS)

The macOS app ships a copy of [tmux](https://github.com/tmux/tmux) at
`nodeterm.app/Contents/Resources/bin/tmux`, statically linked against
[libevent](https://github.com/libevent/libevent) and
[utf8proc](https://github.com/JuliaStrings/utf8proc). It is used **only** when the
machine has no tmux of its own — a tmux found anywhere on the system takes
precedence — so that terminals keep their sessions across restarts. None of the
three projects is modified; `scripts/build-tmux.mjs` builds the pinned upstream
release tarballs unchanged. Their license texts are in `resources/licenses/`
(`tmux-COPYING.txt`, `libevent-LICENSE.txt`, `utf8proc-LICENSE.md`), refreshed
from the tarballs by that same script.

## Bundled fonts

The app is a font-src 'self'/data:-restricted Electron app (see the renderer's
Content-Security-Policy in `src/renderer/index.html`), so every font it uses is committed
locally rather than fetched from a hosted provider. Three families are bundled under
`src/renderer/assets/fonts/`, regenerated by `scripts/build-fonts.mjs` from pinned npm
devDependencies — nothing is fetched at build or run time; each script only reads a package
`npm install` already unpacked into `node_modules/`.

- **[Outfit](https://fonts.google.com/specimen/Outfit)** (variable, UI font) — packaged via
  [`@fontsource-variable/outfit`](https://www.npmjs.com/package/@fontsource-variable/outfit),
  pinned at `5.3.0`. Licensed under the
  [SIL Open Font License 1.1](https://openfontlicense.org/). Full license text:
  `node_modules/@fontsource-variable/outfit/LICENSE`.
- **[Roboto Mono](https://fonts.google.com/specimen/Roboto+Mono)** (code / terminal font) —
  packaged via
  [`@fontsource/roboto-mono`](https://www.npmjs.com/package/@fontsource/roboto-mono), pinned at
  `5.3.0`. Licensed under the SIL Open Font License 1.1. Full license text:
  `node_modules/@fontsource/roboto-mono/LICENSE`.
- **[Material Symbols Rounded](https://fonts.google.com/icons)** (icon font) — packaged via
  [`material-symbols`](https://www.npmjs.com/package/material-symbols), pinned at `0.46.0`,
  designed by Google. Licensed under the
  [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). Full license text:
  `node_modules/material-symbols/LICENSE`. **Subsetted**: nodeterm ships only the 92 glyphs it
  actually uses (`scripts/material-symbols-glyphs.json`), reducing the font from ~5.3 MB to
  ~94 KB, subsetted by codepoint (not by ligature) with `scripts/subset-material-symbols.py`
  using [fontTools](https://github.com/fonttools/fonttools) (MIT-licensed; a build-time-only
  Python dependency, not bundled into the app). The subset preserves every variable axis
  (`FILL`, `wght`, `GRAD`, `opsz`) of the source font exactly — verified automatically by the
  subsetting script, which fails the build if an axis is dropped, altered, or if a requested
  glyph does not survive subsetting. Two of the 92 requested icon names (`smartphone`,
  `system_update`) do not exist in this exact package version; nodeterm renders the nearest
  available equivalents (`mobile`, `system_update_alt`) instead — see the `aliasesApplied`
  field in the generated `scripts/material-symbols-codepoints.generated.json` manifest for the
  exact mapping.
