# Windows features

This category contains Windows-specific desktop features. The diagnostics article is a local,
read-only view of host facts and never performs a host mutation.

## Articles

- [Read-only Windows diagnostics](./windows-diagnostics.md) — inspect drives and storage, services,
  startup entries, scheduled tasks, updates, network state, and bounded event summaries.
- [Windows CLI resolution and npm shim execution](./cli-shim-execution.md): PATHEXT lookup, quoted
  PATH entries, and running npm `.cmd` shims through cmd.exe with escaped arguments and raw stdin.
