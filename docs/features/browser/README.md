# Browser sessions

**Category:** Browser

Browser surfaces are split by purpose. The ordinary browser node is a convenient webview for
reading pages. The isolated debugging browser is a separate, disposable Chromium session for
debugging a page with a proxy and a local DevTools Protocol endpoint.
