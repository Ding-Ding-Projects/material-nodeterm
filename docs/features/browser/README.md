# Browser surfaces

Browser features are grouped here so the regular Browser node and the isolated Browser Portal have
separate contracts. Each article describes the state that is shared in a project file and the
state that stays on the computer that opens it.

## Articles

| Article | Scope |
| --- | --- |
| [Browser node tabs](./browser-tabs.md) | Multi-tab navigation and ordinary browser session partitions. |
| [Browser Portal](./browser-portal.md) | Strict HTTP(S) navigation, isolated local profiles, and safe lifecycle ownership. |
| [Unpacked extensions and WebAuthn](./extensions-and-webauthn.md) | Chromium extension and authenticator boundaries. |
