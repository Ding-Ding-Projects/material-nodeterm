# Help

The surfaces that explain nodeterm from inside nodeterm, rather than sending you to a browser.

- [In-app documentation browser](./in-app-documentation.md) — every `docs/` article compiled into
  the build, readable offline, searchable by plain text or regex, with article-to-article links
  that land on the linked article instead of opening a browser.

See also [Appearance](../appearance/README.md) for the design tokens these surfaces are drawn
with, and [Global and project settings](../global-and-project-settings.md) for the settings
search that indexes the app's own options.
