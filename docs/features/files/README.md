# Files and conversion

Local file workflows that inspect, transform, and hand off user-selected content without sending it
to a network service.

- [Universal file converter](../../file-converter.md): categorized bundled and unavailable adapters,
  bounded detection, collision-safe output names, resumable progress, atomic publication, cancellation,
  partial results, and completed-output handoff to Visual Studio Code.
- [Files node](./files-node.md): one persisted directory listing on the canvas, guided navigation,
  bounded local creation, regex-capable filtering, file routing, and remote-host safety.
