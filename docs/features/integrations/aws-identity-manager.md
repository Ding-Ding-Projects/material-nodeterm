# AWS identity manager

See the complete [AWS identity manager article](../../aws-identity-manager.md). This categorized
entry covers the profile, SSO, role, MFA, region, endpoint, caller-identity, permission, and
machine-local cache boundaries. The feature is deliberately separate from portable project data:
safe profile intent may be recreated on another machine, while credentials and provider sessions
must be configured there again.
