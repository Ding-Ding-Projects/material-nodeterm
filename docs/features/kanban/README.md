# Kanban

Every project is also a Trello-style board. Cards are not a separate data model — they are
the project's live session nodes, viewed a different way.

- [Kanban board](./kanban-board.md) — columns, cards, the card modal (a second live view of
  the session), members, due dates, and the board's activity log.

See also [Canvas](../canvas/README.md) for the node the card mirrors, and
[Agents](../agents/README.md) for the status badges a card shows.
