# Cloud integrations

Cloud integrations are guided from installed, versioned models and local intent. They never turn
an arbitrary shell textbox into an operation runner.

- [AWS CLI model and documentation index](./aws-cli-docs-index.md)

Each article records the local model source, cache and revision behavior, offline fallback, and the
boundary between documentation discovery and an external operation. Related work such as AWS
identity, typed operation wizards, and service managers builds on this index in later lanes.
