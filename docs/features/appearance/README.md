# Appearance

How the application decides what it looks like: its design tokens, its themes, and the state of the
migration toward Material Design 3.

- [Material Design 3 migration status](./material-3-migration-status.md) — measured counts of which
  Material tokens exist, which are actually referenced, and which are declared and inert; what the
  design export asks for; and why the surface ramp is the part that cannot be moved casually.
- [Material Design 3 desktop surface audit](./material-3-audit.md) — the hand-written inventory of
  every desktop shell, node, destination, settings section, overlay, status state, and checked-in
  documentation page, plus the source-level remediation and remaining ownership conflicts.

See also [Canvas](../canvas/README.md), whose node chrome consumes most of these tokens.
