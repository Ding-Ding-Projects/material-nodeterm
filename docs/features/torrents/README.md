# Torrents

The torrent category covers local peer-to-peer downloads. It is deliberately separate from the
application's updater and from browser downloads: every transfer is an explicit canvas task with a
destination, selected files, progress, and a seeding policy.

- [Torrent Downloader](./torrent-downloader.md) - bundled WebTorrent runtime, magnet and
  `.torrent` intake, metadata selection, progress, recovery, and local persistence.
